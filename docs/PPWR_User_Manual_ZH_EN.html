PPWR Digital Platform02 · 项目 / Project

创建项目与适用性
Create a Project & Applicability

Projects → New project → Create project
  1. 填写产品/项目标题、包装系统编号（如 PS-001）、目标日期和预期用途。专家须核对所属客户；客户账号自动归属自己的客户。Enter the product/project title, packaging system ID (e.g. PS-001), target date and intended use. Experts must select the correct client; client accounts use their own client.
  2. 选择技术文件场景 A 或 B。场景影响文件的范围和编号，不能仅为提高完成率而选择。Choose technical-file scenario A or B. It determines document scope and numbering; do not choose it merely to improve completion figures.
  3. 按真实用途勾选 Food-contact packaging、Reusable packaging、Art 9 packaging type、Biobased feedstock claim。Set food-contact, reusable, Article 9 packaging-type and biobased-claim flags according to actual use.
  4. 可填写第一个包装单元名称和层级，也可稍后登记或导入；点击 Create project。Optionally enter the first packaging-unit name and level, or register/import it later; select Create project.
场景 / Scenario输出 / Output
A · Per-unit
按单元		每个包装单元各有一份 TD 和 EU DoC，另有文件包总览供最终包装使用方索引。
One TD and EU DoC per packaging unit, plus a document-package overview for the final packaging user.
B · Consolidated
合并		同一产品各包装单元汇总在一份 TD 和一份 EU DoC 中。
All packaging units of the product are covered by one consolidated TD and one EU DoC.

核对适用性矩阵 / Check the applicability matrix

进入项目 Overview 查看 Applicability matrix 的状态、适用日期和依据。矩阵由项目属性及 BOM 材料组推导；自动 N/A 的理由会写入 TD。

In project Overview, inspect each requirement's status, application date and basis in the Applicability matrix. It is derived from project flags and BOM material groups; automatic N/A rationales feed the TD.

如判断不符，通过 Edit the project profile → Save profile 修正用途属性，并检查 BOM 材料组。修改后重新查看条目状态和文件完成度。
If applicability is incorrect, use Edit the project profile → Save profile and check BOM material groups. Recheck item statuses and document readiness afterward.

PPWR Digital Platform03 · 包装登记 / Packaging Register

包装单元与 BOM
Packaging Units & BOM

Projects → 项目 / Project → Packaging & BOM

登记包装单元 / Register a packaging unit

  1. 展开 + Add a packaging unit，填写名称、层级、类型、UPI、SKU、重量（g）和尺寸（mm）。同时录入供应商、生产地点、国家及图稿引用（如适用）。Expand + Add a packaging unit. Enter name, level, type, UPI, SKUs, mass (g) and dimensions (mm), plus supplier, site, country and artwork reference where relevant.
  2. 点击 Add unit；新增单元获得 PU 编号。已有记录通过行末 Edit 修改，再点击 Save。Select Add unit; the unit receives a PU code. Use row-level Edit and Save for an existing record.

登记 BOM 组件 / Register BOM components

  1. 在包装登记表选择目标单元，展开 + Add a component。将纸盒、膜、盖、标签、油墨、胶黏剂等按独立组件登记。Select the target unit and expand + Add a component. Register parts such as carton, film, cap, label, ink and adhesive as separate components.
  2. 填写组件类型、描述、结构、材料、材料组和重量。填写再生含量百分比、尺寸及备注（如适用）。Enter component type, description, structure, material, material group and mass. Add recycled-content percentage, dimensions and remarks where relevant.
  3. 在 Supplier material (library) 选择供应商材料，点击 Add component 或 Save。未建立材料时，先按第 7 页完成供应商登记。Select a Supplier material (library) and click Add component or Save. If no material exists, complete supplier registration on page 7 first.
关联供应商材料，才能让材料证书参与证据检查，并让后续供应商变更追溯到该组件。仅填写供应商名称不等于建立材料关联。
A supplier-material link enables certificate checks and traces later supplier changes to the component. Entering a supplier name alone does not create this link.

保存后的检查 / Checks after saving

核对组件重量合计与声明的包装重量；检查材料组、SKU 和供应商关联。C01 类字段来自包装登记，应在本页修改，而非在采集条目内修改。

Compare component mass totals with declared unit mass; check material groups, SKUs and supplier links. C01 fields originate in the packaging register and should be edited here, not in collection items.

修改已批准的登记值可能重开相关条目。删除包装单元会同时移除其组件和采集条目；操作前应导出并确认影响。
Changing approved register values may reopen related items. Removing a unit also removes its components and collection items; export and confirm the impact first.

PPWR Digital Platform04 · 工作簿 / Workbooks

Excel 导入与导出
Excel Import & Export

Project → Packaging & BOM → Blank template / Export this BOM
  1. 下载 Blank template（界面链接为 PPWR_BOM_V1.xlsx）；如链接不可用，请联系管理员提供模板。不要用任意自制表格替代。Download Blank template (linked as PPWR_BOM_V1.xlsx). If unavailable, request the template from your administrator; do not substitute an arbitrary workbook.
  2. 按模板一行填写一个组件，保留表头，正确填写 PS / PU / Component ID、材料、重量及供应商信息。Use one row per component. Keep the template headers and complete PS / PU / Component IDs, material, mass and supplier information accurately.
  3. 打开目标项目的 Packaging & BOM，将 .xlsx 文件拖入导入区域，或点击浏览选择。等待导入结果提示。Open the target project's Packaging & BOM. Drop the .xlsx file onto the import area or browse to it, then wait for the result message.
  4. 核对新增/更新的单元和组件、材料组及供应商材料关联；回到 Overview 检查适用性和采集状态。Verify created/updated units and components, material groups and supplier-material links. Recheck applicability and collection statuses in Overview.
导入按编号创建或更新，不是仅追加。请先用 Export this BOM 留存现有数据，再确认导入文件的项目和编号。界面未提供一键撤销导入。
Import creates or updates by ID; it is not append-only. Save an Export this BOM copy and confirm the target project and identifiers first. The interface provides no one-click import undo.
导出入口 / Export entry用途 / Purpose
Export this BOM
Packaging & BOM		导出项目 BOM 工作簿，用于离线检查、沟通或修改后再次导入。
Export the project's BOM workbook for offline checking, communication or later re-import after editing.
Export Evidence List (.xlsx)
Evidence vault		导出证据索引和元数据；不等于下载所有附件。
Export the evidence index and metadata; this does not download all attachments.

导入失败时 / If import fails

如出现 No 'Component ID' header found，检查是否使用正确模板以及表头是否被修改。若材料或供应商未正确关联，先补齐供应商材料，再检查或编辑组件。

For No 'Component ID' header found, check that the correct template is used and its headers are unchanged. If materials or suppliers are not linked correctly, register the supplier materials and inspect or edit the components.

PPWR Digital Platform05 · 供应商库 / Supplier Library

供应商、材料与证书
Suppliers, Materials & Certificates

Suppliers → Add a supplier → 供应商详情 / Supplier details
  1. 在 Add a supplier 输入名称、国家、地址和合规联系人；专家同时选择所属客户。点击 Add supplier。Enter name, country, address and compliance contact in Add a supplier; experts also select the client. Click Add supplier.
  2. 打开供应商，使用 Add a material 登记材料名称、供应商自身的 Trace code、材料及材料组，点击 Add material。Open the supplier and use Add a material to register its name, supplier's own Trace code, material and group; click Add material.
  3. 在目标材料展开 Add / renew a certificate，填写类型、编号、签发机构、结果、签发日期及有效期，可附报告文件；点击 Save certificate。Under the material, expand Add / renew a certificate. Enter type, number, issuer, result, issue date and expiry; optionally attach the report. Click Save certificate.
  4. 回到项目 BOM，将组件关联到此材料；在供应商页面检查 Used by 是否显示预期组件。Link the BOM component to this material and verify that the supplier page's Used by list shows the expected components.

续期与到期提醒 / Renewal & expiry alerts

Expiry watch 显示已到期或剩余不超过 30 天的证书。点击提醒进入材料详情，核实编号、期限和附件；按上述步骤保存新的证书。

Expiry watch shows expired certificates or those expiring within 30 days. Open the material from the alert, verify the number, dates and attachment, and save a new certificate using the steps above.

同类型证书续期会将旧证书标为 superseded；材料已用于 BOM 时，可能产生变更事件。保存新证书后仍需检查 Change impact，不能视为文件已自动重新签发。
Renewal supersedes the previous certificate of the same type and may raise a change event when the material is used in a BOM. Check Change impact afterward; saving a certificate does not automatically re-issue documents.

报告材料或供应商变更 / Report a material or supplier change

展开 Report a material / supplier change，填写变更标题、类别和详情（建议包括生效日期及供应商通知），点击 Trace the impact，按第 13 页处理。

Expand Report a material / supplier change. Enter title, kind and details, preferably including effective date and supplier notice; select Trace the impact and follow page 13.

PPWR Digital Platform06 · 数据采集 / Collection

数据采集与 N/A
Data Collection & N/A

Project → Data collection → 包装单元或 / Unit or Project-level items
  1. 选择包装单元标签，或 Project-level items。项目级条目（如标准、风险分析及 DoC 数据）只采集一次，不要只完成包装单元而遗漏项目级数据。Select a unit tab or Project-level items. Project-level data such as standards, risk analysis and DoC data is collected once; do not overlook it when completing unit data.
  2. 按条目编号/名称搜索，或按状态筛选；展开类别，打开条目。目录含 16 类、73 个要求，含新增 C04-70 至 C04-73（见第 25 页）。Search by item ID/name or filter by status. Open a category/item. The catalogue has 16 categories and 73 requirements, including C04-70 to C04-73 (page 25).
  3. 阅读 Evidence requirements / 证据要求 和五组填写指引（第 19 页），填写 Your entry；点击 Check my entry / 检查我的填写 排查缺漏，表格可用 + Row 增行。Read Evidence requirements and the five guidance folds (page 19). Complete Your entry and use Check my entry to find gaps; use + Row for table rows.
  4. 上传关联证据（见第 9 页），点击 Save draft 暂存，或 Submit for review 提交；可用 Submit & next open item 连续处理。Upload linked evidence (page 9). Select Save draft to save, or Submit for review to submit; Submit & next open item supports consecutive entry.

不适用申请 / Requesting N/A

展开 Not applicable to this packaging?，在 Reason 填写可核查的法规/材料/用途依据（至少 10 个字符），客户点击 Request N/A。申请仍需专家确认，不等于已经关闭。

Expand Not applicable to this packaging?. Enter a verifiable legal, material or use-based rationale in Reason (at least 10 characters). Clients select Request N/A; expert confirmation is still required before closure.

自动 N/A 来自适用性矩阵，不应通过编写无依据的理由绕过采集。若自动判断不正确，应修正项目属性或 BOM。N/A 理由会引用到 TD §5 / §19。
Automatic N/A comes from the applicability matrix. Do not bypass collection with unsupported rationales. Correct the project profile or BOM if the automatic result is wrong. N/A rationales are quoted in TD §5 / §19.

平台组装条目 / Platform-assembled items

显示 Assembled by the platform 的条目由 BOM、矩阵或证据登记等来源组装；通过页面提供的入口修改源数据，不寻找不存在的手工输入框。

Items marked Assembled by the platform are built from sources such as the BOM, matrix or evidence register. Follow the source-editing links instead of looking for manual entry fields.

PPWR Digital Platform07 · 证据 / Evidence

上传与管理证据
Upload & Manage Evidence

首选：从采集条目上传 / Preferred: upload from an item

  1. 在条目的 Evidence / 证据文件 区域选择文件，按该条目显示的格式要求准备附件，每个文件最大 25 MB。格式或条目匹配异常时会出现提醒。Choose a file in Evidence using the formats displayed for that item; the limit is 25 MB per file. Unusual formats or possible item mismatches trigger warnings.
  2. 填写标题、证据类型、组件（或 whole unit）、报告编号、签发机构、签发日期及 Conformity。选择实际结果，不要将不符合报告标为符合。Enter title, evidence type, component (or whole unit), report number, issuer, issue date and Conformity. Record the actual result; never label non-conforming evidence as conforming.
  3. 点击 Upload to the vault，核对生成的证据编号和链接，点击标题验证文件能下载，然后提交条目。Select Upload to the vault. Check the generated evidence ID and link, verify the file downloads from its title, then submit the item.

综合证据与登记表 / Combined evidence & the register

进入项目 Evidence vault，按单元和类型筛选、点击证据编号下载，或用 Export Evidence List (.xlsx) 导出索引。综合声明可在 Add a file that is not tied to one item 上传，并选择单元/组件。

In project Evidence vault, filter by unit/type, download by evidence ID or use Export Evidence List (.xlsx). Upload combined declarations under Add a file that is not tied to one item and select the unit/component.

综合文件未必自动满足某一采集条目的证据要求。对关键要求，优先从相应条目上传，确保条目、单元、组件和报告对应。已批准条目的附件操作可能被锁定，应联系专家重开。
A general upload may not automatically satisfy a specific collection item. Upload critical evidence from its item to ensure correct item, unit, component and report alignment. Approved-item attachments may be locked; ask the expert to reopen the item.
提示 / Indicator处理 / Action
> 24 months核实报告是否仍代表当前材料及用途，必要时补充新证据；这是试点检查阈值，并非所有报告统一的法定有效期。
Check continued relevance to the current material/use and refresh where needed. This is a pilot check threshold, not a universal legal expiry period.
Non-conform提交真实结果并处理不符合，不得通过修改元数据隐藏问题。
Record the actual result and resolve the non-conformity; do not hide it by editing metadata.
组件缺证据提示
Missing evidence		为组件上传至少一份相关证据，或建立有效的供应商材料关联。
Upload relevant component evidence or establish a valid supplier-material link.

PPWR Digital Platform08 · 预审与待办 / Pre-review & Actions

AI 预审与客户待办
AI Pre-review & Client Actions

运行与阅读预审 / Run & read pre-review

  1. 提交条目后，查看右侧 AI pre-review。若显示等待，点击 Run AI pre-review；已有结果时可用 Re-run。After submission, inspect the right-hand AI pre-review panel. If pending, click Run AI pre-review; use Re-run when a result already exists.
  2. 逐项查看检查描述、提示和法规引用，不要只看总体结论。检查涉及完整性、限值、项目属性/BOM 一致性、证据日期及供应商证书。Read each check, message and source reference, not only the overall verdict. Checks cover completeness, limits, profile/BOM consistency, evidence dates and supplier certificates.
  3. 缺失、过期或矛盾的数据应补充或更正；保存并重新提交后再次运行预审，等待专家决定。Correct missing, stale or inconsistent data. Save and resubmit, rerun pre-review and await the expert's decision.
结果值 / Verdict含义与操作 / Meaning & action
pass规则检查未发现问题；仍须专家审核，不等于法规符合性认证。
No issues found by the rule checks; expert review is still required. This is not conformity certification.
warn存在注意项或待判断事项；补充依据，供专家判断。
Attention points or judgment needed; provide supporting information for the expert.
fail存在明确检查失败；阅读具体信息，处理后重新提交。
One or more checks failed; read the messages, resolve the issues and resubmit.

客户处理退回 / Client rework

进入顶部 My actions，打开退回条目；阅读 Sent back by 的审核意见。若显示 Re-opened，核对重开原因。修正字段和附件后点击 Submit for review，不要仅保存草稿。
